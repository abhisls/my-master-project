# 📸 CameraWaleSir Full-Stack Portfolio

यह एक ऑल-इन-वन आर्किटेक्चर प्रोजेक्ट है जो एक प्रोफेशनल फोटोग्राफी वेबसाइट के साथ-साथ सभी प्रमुख फाइल एक्सटेंशन्स को प्रदर्शित करता है।

## 🚀 फीचर्स
- **HTML/CSS/JS/MJS:** कोर फ्रंटएंड और मॉडर्न मॉड्यूल।
- **JSON Driven:** गैलरी डेटा `data.json` से ऑटो-लोड होता है।
- **Multi-Backend Storage:** इंटरव्यू प्रदर्शन के लिए Python, PHP, Java, Ruby और Go सर्वर्स शामिल हैं।
